## 1. 카카오 로그인 (Kakao OAuth 2.0) — 소셜 인증

| 항목 | 내용 |
| --- | --- |
| 용도 | 소셜 로그인 (인가코드 → 토큰 교환 → 사용자 정보 조회) |
| 가입 | https://developers.kakao.com → 애플리케이션 생성 |
| 사용 API | `https://kauth.kakao.com/oauth/token`, `https://kapi.kakao.com/v2/user/me` |
| 필요 값 | REST API 키(= `KAKAO_CLIENT_ID`, `VITE_KAKAO_CLIENT_ID`), Client Secret(= `KAKAO_CLIENT_SECRET`) |

**콘솔 설정 절차**

1. 내 애플리케이션 → 앱 생성 → **REST API 키** 확인
2. 카카오 로그인 활성화 → **Redirect URI 등록**: `https://eyedontcare.shop/auth/kakao/callback`
3. 보안 → **Client Secret 생성** 및 "사용함" 설정
4. 동의항목: 닉네임 등 서비스가 사용하는 항목 설정

**주의**: Redirect URI는 3곳(카카오 콘솔 / 프론트 `VITE_KAKAO_REDIRECT_URI` / 백엔드 `KAKAO_REDIRECT_URI`)이 문자 단위로 일치해야 합니다. `VITE_` 값은 프론트 빌드 시점에 번들로 구워지므로 변경 시 재배포가 필요합니다.

## 2. OpenVidu 3.x / LiveKit — WebRTC 미디어 서버 (화상 대결)

| 항목 | 내용 |
| --- | --- |
| 용도 | 친구 대결·랜덤 매칭 시 실시간 영상/음성 (WebRTC) |
| 설치 | OpenVidu **3.8.0** self-hosted single-node 배포 (https://openvidu.io) — OpenVidu 3.x는 LiveKit 호환. 서비스와 같은 EC2에 배포됨 |
| 구성 컨테이너 | openvidu(livekit-server, 내부 7880), ingress, egress, caddy, meet, dashboard, operator, minio, mongo, redis + 모니터링(grafana/prometheus/loki/alloy) |
| 백엔드 연동 | `io.livekit:livekit-server:0.14.0` SDK로 미디어 접속 토큰(JWT) 서명·발급 |
| 필요 값 | `OPENVIDU_URL` = `wss://i15b102.p.ssafy.io:7443` (호스트 Nginx가 7443 SSL → 내부 7880으로 프록시), `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` |

**설정 절차**

1. EC2에 OpenVidu 3.8.0(single-node) 배포 — 배포 시 생성되는 API Key/Secret 확인
2. 백엔드 환경변수에 동일한 `LIVEKIT_API_KEY` / `LIVEKIT_API_SECRET` 주입 (서버 값과 불일치 시 토큰 검증 실패)
3. 호스트 Nginx에 7443 SSL 프록시(→ 127.0.0.1:7880, WebSocket 업그레이드) 설정 — 01번 문서 §7 참고
4. 보안 그룹에서 7443/TCP 및 WebRTC용 UDP 범위 개방
5. 프론트엔드는 `livekit-client` SDK로 접속 (백엔드가 발급한 토큰 사용)

## 3. SSAFY GMS (OpenAI 호환 게이트웨이) — AI 그림 채점

| 항목 | 내용 |
| --- | --- |
| 용도 | "눈으로 그리기(draw)" 게임의 그림 인식·채점 (gpt-4o Vision) |
| 엔드포인트 | `https://gms.ssafy.io/gmsapi/api.openai.com/v1/chat/completions` (`GMS_BASE_URI`) |
| 발급 | SSAFY GMS 포털에서 API 키 발급 |
| 필요 값 | `GMS_API_KEY` (필수), `GMS_MODEL`(기본 `gpt-4o`) |

**주의**

- 키가 없어도 서비스는 정상 기동하며, 그림 인식 API만 비활성(에러코드 GAME-003) 응답합니다.
- Vision 채점은 30초 이상 걸릴 수 있어 백엔드 read-timeout 60s, Nginx `proxy_read_timeout` 120s로 설정되어 있습니다. 프록시 계층 추가 시 동일하게 맞춰야 합니다.

## 4. SeeSo (Eyedid) — 시선 추적 SDK (선택)

| 항목 | 내용 |
| --- | --- |
| 용도 | 웹캠 기반 시선 추적 정확도 향상 (미설정 시 MediaPipe 시선 추정으로 자동 폴백) |
| 가입 | https://console.seeso.io → 라이선스 키 발급 |
| 필요 값 | `VITE_SEESO_LICENSE_KEY` (프론트 빌드 시점 주입) |

**주의**: 라이선스 키는 콘솔에 **등록한 도메인에서만 유효**합니다. 운영 도메인을 콘솔에 등록해야 하며, 키 변경 시 프론트엔드 재빌드가 필요합니다.

## 5. MediaPipe Tasks Vision — 얼굴/눈 인식 (별도 가입 불필요)

- Google MediaPipe 기반 눈 깜빡임·시선 추정. 프론트엔드 번들에 포함되어 **별도 계정·키가 필요 없습니다.**
- 단, 스레드 WASM(SharedArrayBuffer) 사용을 위해 **COOP/COEP 헤더**(`same-origin` / `require-corp`)가 응답에 포함되어야 합니다. 헤더가 빠지면 웹캠 기능이 조용히 실패합니다.
